# Visão Administrativa Multi-loja

Painel gerencial exclusivo do administrador em `/admin-multiloja.html`.

- consolida KPIs sem juntar cadastros operacionais;
- usa tokens temporários por loja autorizada;
- restaura a loja ativa original após a leitura;
- permite filtrar uma loja ou todas;
- permite entrar diretamente em uma unidade específica;
- acesso visual disponível em Configurações pelo botão **Visão Multi-loja**.
